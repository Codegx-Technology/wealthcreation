# Email Notification Setup Guide

The wealth creation registration system now includes automatic email notifications that will send registration details to `info@suzzyevents.com` whenever someone completes their registration.

## 🔧 Setup Instructions

### Step 1: Install Dependencies
```bash
cd wealthcreation
npm install nodemailer@^6.9.0
```

### Step 2: Configure Email Settings
Create/update your `.env` file with email credentials:

```bash
# Email Configuration
EMAIL_USER=info@suzzyevents.com
EMAIL_PASSWORD=your-app-password-here
```

### Step 3: Email Provider Setup Options

#### Option A: Gmail Setup (Recommended)
1. Go to your Gmail account settings
2. Enable 2-Factor Authentication
3. Generate an App Password:
   - Google Account → Security → 2-Step Verification → App Passwords
   - Select "Mail" and generate password
4. Use the generated password in `EMAIL_PASSWORD`

#### Option B: Outlook/Hotmail Setup
1. Go to Microsoft Account security settings
2. Enable 2-Factor Authentication
3. Generate App Password for Mail
4. Use generated password in `EMAIL_PASSWORD`

#### Option C: Custom SMTP Setup
Modify the email configuration in `server.js`:
```javascript
emailTransporter = nodemailer.createTransporter({
  host: 'your-smtp-server.com',
  port: 587,
  secure: false,
  auth: {
    user: 'info@suzzyevents.com',
    pass: 'your-password'
  }
});
```

### Step 4: Test the Setup
1. Start the server: `npm start`
2. Submit a test registration
3. Check your email for notifications

## 🔍 Monitoring & Troubleshooting

### Check Email Status
Monitor server logs for email notifications:
```
[EMAIL] ✅ Email transporter configured
[EMAIL] Admin notification sent for registration: John Doe
[EMAIL] Confirmation sent to participant: john@example.com
```

### Common Issues
1. **Authentication Failed**: Use App Password, not regular password
2. **Emails Not Sending**: Check SMTP settings and internet connection
3. **Missing Emails**: Check spam folder, verify email addresses

### Backup Collection Method
Even if emails fail, all registrations are logged in server console:
```
[API req_xxx] Registration request received
New registration: {full registration data}
```
